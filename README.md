# بوت تيليجرام لإنشاء التقارير الجامعية (Word + PDF)

بوت يستقبل بيانات التقرير من المستخدم، ثم يستخدم **قالب Word الجاهز** `template/template.docx`، فيستبدل المتغيرات
(`{{title}}` و`{{student_name}}` و`{{professor_name}}` و`{{content}}`)، وينسّق محتوى التقرير، وينشئ ملف Word
ثم يحوّل **نفس الملف** إلى PDF عبر LibreOffice، ويرسل الملفين للمستخدم.

القالب هو المصدر الوحيد للتصميم: الكود لا يعيد بناء الغلاف ولا الشعار ولا الهوامش ولا الترقيم.
ولا يعدّل `template.docx` الأصلي أبداً (يعمل على نسخة مؤقتة لكل عملية).

---

## 1) تثبيت Python

1. نزّل Python 3.10 أو أحدث من <https://www.python.org/downloads/>.
2. على Windows فعّل الخيار **Add python.exe to PATH** أثناء التثبيت.
3. تحقق:

```bash
python --version
```

## 2) إنشاء بوت من BotFather

1. افتح تيليجرام وابحث عن `@BotFather`.
2. أرسل `/newbot` واتبع التعليمات (اسم البوت ثم معرّف ينتهي بـ `bot`).

## 3) الحصول على BOT TOKEN

يرسل لك BotFather رسالة فيها التوكن بهذا الشكل: `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.
**لا تشاركه مع أحد.** إذا تسرّب أرسل `/revoke` إلى BotFather لتوليد توكن جديد.

## 4) وضع التوكن في `.env`

افتح ملف `.env` (أو انسخ `.env.example` إلى `.env`) واكتب:

```text
BOT_TOKEN=123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

الملف `.env` مُضاف إلى `.gitignore` ولا يُرفع إلى Git. والبوت لا يكتب التوكن في السجلات.

## 5) وضع قالب Word

ضع القالب في هذا المسار بالضبط (اسم واحد وقالب واحد فقط):

```text
template/template.docx
```

## 6) تثبيت المتطلبات

```bash
cd telegram-report-bot
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux / macOS:
source venv/bin/activate

pip install -r requirements.txt
```

## 7) تثبيت LibreOffice

مطلوب لتحويل Word إلى PDF.

- **Windows:** نزّله من <https://www.libreoffice.org/download/> وثبّته بالإعدادات الافتراضية
  (يُكتشف تلقائياً من `C:\Program Files\LibreOffice`). إذا ثبّتّه في مكان آخر فأضف في `.env`:
  `LIBREOFFICE_PATH=D:\Apps\LibreOffice\program\soffice.exe`
- **Ubuntu / Debian (VPS):**

```bash
sudo apt update
sudo apt install -y libreoffice-writer libreoffice-math fonts-noto-core fonts-noto-naskh-arabic
```

> **مهم:** الحزمة `libreoffice-math` ضرورية لظهور **المعادلات** في ملف PDF (في Windows تأتي مع التثبيت الكامل).
> بدونها يبقى Word سليماً لكن المعادلات تختفي من PDF. البوت يكتب تحذيراً في السجل عند عدم وجودها (على Linux).

**الخطوط:** القالب يستخدم الخط **Simplified Arabic**. هو موجود مع Windows/Office، فيخرج PDF مطابقاً للقالب.
على Linux ثبّت نفس الخط (أو بديلاً قريباً) وإلا سيستبدله LibreOffice بخط آخر وقد يتغير توزيع الأسطر في الغلاف وفي PDF فقط
(ملف Word نفسه لا يتأثر).

## 8) تشغيل البوت

```bash
python bot.py
```

السجلات في `logs/bot.log` (التفاصيل التقنية تُسجَّل للمطور فقط، ولا تُعرض للمستخدم).

## 9) طريقة استخدام البوت

1. أرسل `/start` ثم اضغط **🚀 ابدأ استخدام البوت**.
2. أرسل بالترتيب: عنوان التقرير ← اسم الطالب ← اسم المشرف ← محتوى التقرير.
3. المحتوى يمكن إرساله برسالة واحدة أو عدة رسائل (تُحفظ بالترتيب). اضغط **➕ إضافة جزء** أو أرسل الجزء التالي مباشرة،
   وعند الانتهاء اضغط **✅ انتهت كتابة التقرير**.
4. راجع البيانات ثم اضغط **✅ ابدأ الطباعة**، أو **✏️ تعديل البيانات** لتعديل أي حقل بشكل مستقل.
5. يصلك ملف Word ثم ملف PDF باسم الطالب. اضغط **🔄 تقرير جديد** لبدء تقرير آخر.
6. **❌ إلغاء** (أو `/cancel`) في أي مرحلة يحذف الجلسة وبيانات التقرير.

**ملاحظات على المحتوى:**

- تيليجرام يقسّم الرسالة التي تتجاوز 4096 حرفاً تلقائياً إلى عدة رسائل. البوت يدمج الأجزاء حسب ترتيب وصولها
  (حسب `message_id`) ويوصل الجزء المقسوم تلقائياً بمسافة بدل فقرة جديدة.
- كل سطر في المحتوى يصبح فقرة. الأسطر الفارغة لا تُنشئ فقرات فارغة (التباعد 1.5 يكفي بين الفقرات).
- تيليجرام يرسل نصاً عادياً فقط، لذا لا يوجد تنسيق مسبق (Bold/مائل) في الإدخال ليُحفظ.

**تنسيق المحتوى المطبَّق تلقائياً (على `{{content}}` فقط):** اتجاه RTL، خط القالب نفسه، حجم **14**، تباعد أسطر **1.5**،
ومحاذاة ضبط (Justify) كما في القالب. الغلاف والعناصر الأخرى لا تُمسّ.

**العناوين Bold:** تُكتشف الأسطر القصيرة (حتى 90 حرفاً ولا تنتهي بعلامة ترقيم نهائية) التي هي:
المقدمة، الخاتمة، المصادر، المراجع، أولاً … عاشراً (مع عنوان أو بدونه)، أو التي تبدأ بترقيم مثل `1.` و`2-` و`3)`.
يُجعل **العنوان وحده** Bold ولا تتأثر الفقرات التالية.

## 10) طريقة تغيير قالب Word

1. افتح القالب الجديد في Word وتأكد أنه يحتوي المتغيرات الأربعة (انظر البند التالي).
2. احفظه باسم `template.docx` وضعه في `template/` مستبدلاً القديم.
3. لا حاجة لإعادة تشغيل البوت (القالب يُقرأ عند كل طلب).

لا يوجد قالب ثانٍ ولا قائمة لاختيار القالب عمداً.

## 11) طريقة تعديل Placeholder

المتغيرات الحالية: `{{title}}` · `{{student_name}}` · `{{professor_name}}` · `{{content}}`.

- اكتب المتغير في Word كما هو، ويُفضَّل **كتابته دفعة واحدة** (حتى لو قسّمه Word إلى عدة Runs فالبوت يتعامل مع ذلك).
- تنسيق أول حرف من المتغير (خط، حجم، لون، Bold) هو الذي ينتقل إلى القيمة المستبدلة.
- يُدعم المتغير داخل: الفقرات، الجداول، **مربعات النص (Text Boxes)**، الترويسات، التذييلات.
- `{{content}}` يجب أن يكون في فقرة مستقلة، وخطه ولغته يؤخذان منها (حجمه يُفرض 14).
- يمكن وضع مسافات داخل الأقواس: `{{ title }}`.

## 12) طريقة إضافة Placeholder جديد

1. أضف المتغير الجديد في القالب، مثلاً `{{department}}`.
2. في `services/word_generator.py` أضف اسمه إلى التعبير النمطي:

```python
_SIMPLE_PLACEHOLDER = re.compile(r"\{\{\s*(title|student_name|professor_name|department)\s*\}\}")
```

3. أضف قيمته إلى القاموس `values` داخل `generate_report_docx` (وإلى معاملات الدالة).
4. أضف حالة جديدة في `handlers/report.py` لسؤال المستخدم عنه (انسخ نمط `got_professor`)،
   ثم أضفه إلى شاشة المراجعة وقائمة التعديل في `utils/keyboards.py`.

## 13) طريقة عمل الجداول

يكتشف البوت الجدول عندما تكون **سطرين أو أكثر متتالية** لها **العدد نفسه من الأعمدة**، ويحوّله إلى **جدول Word حقيقي قابل للتحرير**:

```text
البيان | المبلغ | النسبة
المبيعات | 500000 | 25%
المصروفات | 300000 | 15%
```

- الفاصل: `|` أو Tab أو مسافتان فأكثر (في الأخيرة: خلايا قصيرة، ولا يُعدّ ترقيم القوائم مثل `1.  نص` جدولاً).
- صف الفاصل الخاص بـ Markdown (`---|---`) يُتجاهل.
- الجدول RTL: العمود الأول يظهر في أقصى اليمين مع بقاء ترتيب البيانات كما كتبتها. الصف الأول عنوان (Bold بخلفية رمادية فاتحة).
- **إذا كانت بنية الجدول غير مؤكدة** (أعمدة غير متساوية بين الأسطر مثلاً) يبقى النص كما هو دون تخمين.
- الفراغ بين الجدول وما بعده يُضاف تلقائياً.

## 14) طريقة كتابة المعادلات الرياضية

اكتب المعادلة في **سطر مستقل** يحتوي على `=` ولا ينتهي بنقطة:

```text
I = P × R × T
FV = PV(1 + r)^n
A = P(1 + r/n)^(nt)
ROI = (صافي الربح ÷ الاستثمار) × 100
الفائدة = رأس المال × معدل الفائدة × الزمن
```

- **المعادلات اللاتينية** (متغيرات وأرقام ورموز) تتحول إلى **Word Equation حقيقية قابلة للتحرير**: الأسس `^`، الأدلة `_`،
  الكسور `a/b`، الجذور `√x` أو `sqrt(x)`، الأقواس، `× ÷ + - = ≤ ≥ ≈`.
- **لا تُحَل المعادلة ولا تُختصر ولا تُعاد صياغتها**. وقبل الإدراج يتحقق الكود أن كل محرف كتبته موجود في الناتج،
  وإلا يبقيها نصاً كما هي.
- المعادلة التي تحتوي **كلمات عربية** تبقى **نصاً منسقاً RTL في منتصف الصفحة** بنفس ترتيبها كما كتبتها (انظر القيود أدناه).
- الأسطر التي تنتهي بنقطة أو الطويلة جداً تُعامل كنص عادي.

## 15) حدود الدعم (Text Boxes وWord Equations)

**Text Boxes**
- `python-docx` لا يصل إلى مربعات النص، لكن البوت يعدّلها على مستوى XML مباشرة، وقد اختُبر ذلك على القالب الحالي
  (المتغيرات الموجودة في غلاف القالب داخل مربعات نص، بنسختيها Choice وFallback).
- غير مدعوم: متغير داخل عناصر لا تُخزَّن كنص عادي في المستند، مثل SmartArt أو المخططات (Charts) أو WordArt المحوَّل لصورة.
- `{{content}}` يُدرج في فقرة عادية (أو خلية جدول أو مربع نص) في جسم المستند، ويُفضّل أن يكون في الجسم الرئيسي.

**Word Equations**
- المعادلات **العربية لا تتحول إلى Equation** عمداً: محرر معادلات Word يرتّب العناصر من اليسار إلى اليمين دائماً،
  فتظهر المعادلة العربية معكوسة الترتيب، والأولوية عندنا هي عدم قلب المعادلة. لذلك تبقى نصاً RTL صحيحاً غير قابل للتحرير كمعادلة.
- المعادلات اللاتينية المعقدة جداً (رموز غير مدعومة، أقواس غير متوازنة) تبقى نصاً منسقاً، ولا تُحذف أبداً.
- مصفوفات، تكاملات، مجاميع بحدود، وأشكال الأقواس المتخصصة غير مدعومة في المحوّل.
- في PDF تعتمد جودة رسم المعادلات على LibreOffice Math (انظر البند 7)؛ في Word تظهر بخط Cambria Math.

## ملاحظات تقنية

- **التزامن:** يعمل البوت بـ `concurrent_updates`، وتحويل PDF يجري في Thread منفصل (`asyncio.to_thread`)، فلا يتوقف البوت عن بقية المستخدمين.
  لكل مستخدم جلسته المستقلة، وعدد عمليات LibreOffice المتزامنة محدود بـ `MAX_CONCURRENT_CONVERSIONS` (الافتراضي 2).
- **الأمان:** مجلد مؤقت عشوائي لكل عملية، اسم الملف يُنظَّف من محارف Windows غير المسموحة (مع إبقاء العربية)،
  ولا يتحكم المستخدم بأي مسار. لا تُحفظ التقارير بعد الإرسال.
- **أسماء الملفات:** `اسم الطالب.docx` و`اسم الطالب.pdf` فقط، وإذا لم يتوفر الاسم: `تقرير`.
- **متغيرات بيئة اختيارية:** `LIBREOFFICE_PATH` و`MAX_CONCURRENT_CONVERSIONS` و`PDF_TIMEOUT_SECONDS`.
- **النشر على VPS (Linux):** شغّل `python bot.py` عبر `systemd` أو `supervisor` أو `tmux`، بعد تثبيت LibreOffice والخطوط (البند 7).
